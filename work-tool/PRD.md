الان بعد ان قمنا بأنشاء مشروع laravel
الان اول شي اريد عمله هو انشاء PRD Documentation للمشروع
بحيث المشروع سوف يكون كالاتي
سوف يكون هنالك:
1- نظام المستخدمين (الصلاحيات)
    1- super-admin: هذا المستخدم عندة صلاحية في كل شيئ بداخل الموقع
        ويستطيع انشاء مستخدم جديد (admin - super-admin):
         1- اسم المستخدم
         2- بريدة الالكتروني
         3- كلمة السر
         4- ملاحظة (اختياري) يشوفها فقط super-admin
     عند انشاء المستخدم سوف يتم ارسال بريد الكتروني للمستخدم يتظمن فيها رابط الموقع وبيانات تسجيل الدخول
    2- admin: هذا المستخدم عندة نفس صلاحيات super-admin ماعدا اداراة المستخدمين
    
2-  منتجات
    1- العنوان
    2- الصور الرئيسية
    3- صور اخرى (اختياري)
    4- وصف
    5- الفئة

3- صفحة اتصل بنا
    1- عنوان الصفحة
    2- وصف للصفحة
    3- form contact (flexble)
    4- الايميل المراد ارسال له ال form
    5- الموقع (google map)
    6- رقم الهاتف
    7- وسوف ايضا تحتوي على روابط التواصل الاجتماعي بحيث يستطيع ال admin بأضافة اكثر من رابط بأختيار الايقونة المناسبة للمنصة وايضا وضع الرابط
   
4- صفحة من نحن 
   1- عنوان
   2- عنوان ثانوي (اختياري)
   3- وصف
   4- مميزات (multi)

5- الاعدادات
     1- اسم الوقع
     2- شعار الموقع
     3- الوصف
     4- keywords
     5- faveico
     6- secondary_color
     7- accent_color
     8- background_color

6- صفحة البريد الالكتروني
      1- هنا سوف يتم عرض نسخة من البريد المرسل عنطريق form contact
      2- ايضا سوف يتم عرض احصائيات البريد

7- نظام الاشعارات
    1- اشعارات للبريد الالكتروني
    2- اشعار عمليات تسجيل الدخول
    3- ايضا ممكن تقترح لي انت ايش عاد نضيف هنا
   
8- صفحة Dashboard
     1- عرض احصائيات عامة عن الموقع
     2- عرض عدد زيارات الموقع
     3- عرض عدد مرات التواصل (contact form)
     5- عرض عدد مرات التواصل (هنا سوف سوف يتم احتساب عدد مرات التواصل على حسب عدد مرات النقر على ازرار معينة سوف اضعها في الموقع مثل زر واتساب وايضا ازرار التواصل الاجتماعي)
     6- عدد المستخدمين 
     7- [واحصائيات اخرى انت اقترحها لي]

سوف نعمل على لوحة تحكم المدمجة في laravel: Laravel Starter Kit
